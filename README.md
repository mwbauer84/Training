# Bauer Training — guided workout player

Static web app (index.html + data.js + app.js). Host free on GitHub Pages:
1. github.com → New repository → name `training` → Public → Create.
2. "uploading an existing file" → drag index.html, data.js, app.js → Commit.
3. Settings → Pages → Source: Deploy from a branch → Branch: main / root → Save.
4. Site appears at https://<your-username>.github.io/training/ in ~1 minute.

Logs are saved in each device's browser (localStorage). Export CSV from History.
